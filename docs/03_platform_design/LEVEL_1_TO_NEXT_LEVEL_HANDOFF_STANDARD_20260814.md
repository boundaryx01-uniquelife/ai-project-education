# LEVEL 1 → LEVEL 2~4 프로젝트 인계 기준

- 작성일: 2026-08-14
- 상태: 프로젝트 내부 기준
- 적용: 통합 포털의 LEVEL 1 이후 작업

## 목적

LEVEL 1에서 확인한 문제, 사용자, 규칙, 검증 결과와 제한 사항을 프로젝트 안에 남긴다. 이 문서는 공용 Skill이 아니며, 이 저장소 안의 교육 산출물과 모듈 설계에만 사용한다.

LEVEL 1~4는 각각 독립적으로 완결되는 과정이다. 이 기록은 다른 LEVEL의 필수 선수자료나 자동 입력값이 아니다. 다음 LEVEL을 새로 설계할 때 참고할 수 있는 선택 자료일 뿐이다.

## 인계에 반드시 포함할 항목

1. 프로젝트명, 사용자, 해결할 문제와 원하는 결과
2. 필수 입력과 현재 MVP 규칙·조건
3. 수정에서 확정한 행동·제약
4. MVP 버전과 사용자·AI 검증 이력
5. 알려진 제한·유의 사항
6. 저장, 배포, 공유, 데이터베이스, 외부 API 판단
7. 다음에 추가할 기능

## 다음 LEVEL에서의 사용 원칙

| 다음 단계 | LEVEL 1 인계 자료의 역할 | 새로 확인할 사항 |
| --- | --- | --- |
| LEVEL 2 | 참고 가능한 과거 프로젝트 사례 | 새 프로젝트의 화면·입력·출력, 빈 입력, 오류, 새로고침, 배포 주소, 사용 안내 |
| LEVEL 3 | 참고 가능한 문제·규칙 사례 | 새 프로젝트의 출처, 사용 조건, 기준 날짜, 스키마, 오류·개인정보·권한 |
| LEVEL 4 | 참고 가능한 운영 범위 사례 | 새 프로젝트의 헌장, 역할·승인, 저장소, 테스트, Release, 복구와 개선 |

## 변경 통제

- 인계 자료는 다음 단계의 범위 확장에 대한 자동 승인이나 완료 증거가 아니다.
- 사용자, 문제, 필수 입력, 규칙·조건을 바꾸면 변경 이유와 새 검증을 기록한다.
- API, 데이터베이스, 개인정보, 권한, 외부 자료를 추가하면 해당 범위의 위험과 오류를 별도로 검증한다.
- LEVEL 1의 검증 결과는 더 넓은 기능·데이터 범위에 그대로 재사용하지 않는다.
