# LEVEL 1 포털 모듈 명세

- 작성일: 2026-08-05
- 상태: PROPOSED_FOR_APPROVAL
- 대상 모듈: 근거 기반 수업 프로젝트 설계 미니 에이전트
- 구현 위치: `portal/modules/level-1-chat-agent/`

## 1. 목적

통합 교육포털은 설명 페이지가 아니라 학습자가 DEFINE부터 IMPROVE까지 직접 입력하고, 채팅형 AI에 전달할 Context Packet을 만들며, 테스트와 수정 기록을 저장하는 작업 환경이어야 한다.

## 2. 기본 화면

### 왼쪽 영역

- 7단계 생명주기
- 현재 단계 표시
- 단계별 완료 상태
- 이전·다음 이동

### 가운데 영역

- 현재 단계의 목적
- 기준 예시
- 잘못된 예시
- 입력 양식
- 완료 조건

### 오른쪽 영역

- 조립된 Context Packet
- 복사 버튼
- AI 결과 붙여넣기 또는 요약 기록
- State Snapshot
- 교사 점검 알림

## 3. 단계별 기능

### STEP 0 체험

- 단일 프롬프트 결과와 단계형 결과 비교 카드
- 차이점 3개 기록

### DEFINE

- 사용자, 장면, 문제, 제약, 성공 조건 입력
- 범위가 지나치게 넓을 때 축소 안내
- 프로젝트 브리프 내보내기

### COLLECT

- 자료 3건 이상 입력
- 출처, 작성 주체, 작성일, 원문 위치와 제한 입력
- 개인정보 입력 금지 경고
- 자료 번호 S1, S2, S3 자동 부여

### STRUCTURE

- 필수 입력 정의
- 처리 단계 4~6개 정렬
- 출력 형식과 중단 조건 작성
- 입력 → 단계 → 출력 연결 미리보기

### BUILD

- 에이전트 카드 자동 조립
- 현재 단계용 Context Packet 생성
- 단계 완료 후 State Snapshot 생성
- 전체 대화 재전송을 피하도록 요약 사용 안내

### TEST

- 정상·경계·실패 테스트 탭
- 예상 행동, 실제 행동, 문제와 수정 기록
- 세 테스트가 모두 없으면 다음 단계 이동 제한

### PUBLISH

- 공유 패키지 미리보기
- Markdown 내보내기
- 클립보드 복사
- JSON 내보내기는 확장 기능으로 둔다.

### IMPROVE

- 동료 피드백 3문장 입력
- 수정 전후 기록
- 최종 완료 게이트 확인

## 4. 저장 방식

초기 버전은 서버와 로그인 없이 브라우저 `localStorage`를 사용한다.

저장 항목:

- 프로젝트 메타데이터
- 단계별 입력
- 자료 목록
- Context Packet
- State Snapshot
- 테스트 기록
- 수정 기록

주의:

- 개인정보와 민감정보를 저장하지 않는다는 안내를 항상 표시한다.
- 사용자가 전체 데이터를 삭제할 수 있는 버튼을 제공한다.
- 브라우저·기기 변경 시 자동 동기화되지 않음을 알린다.

## 5. 내보내기

### 필수

- 프로젝트 브리프 Markdown
- 자료 비교표 Markdown
- 에이전트 카드 Markdown
- 테스트 기록 Markdown
- 전체 공유 패키지 Markdown

### 선택

- 전체 프로젝트 JSON
- 인쇄용 HTML

## 6. 교사용 모드

초기 MVP의 교사용 모드는 로그인 기반 모니터링이 아니다.

제공 기능:

- 현재 단계별 점검 질문
- 시간 운영 안내
- 흔한 실패 유형
- 강제 중단이 필요한 안전 신호
- 수업 종료 확인표

학생 또는 참가자의 개별 내용을 서버로 수집하지 않는다.

## 7. 접근성과 오프라인

- 키보드만으로 단계 이동과 입력이 가능해야 한다.
- 고대비 라이트 테마를 기본으로 한다.
- 작은 화면에서도 입력과 Context Packet을 전환해 볼 수 있어야 한다.
- 정적 파일만으로 로컬 실행할 수 있어야 한다.
- 외부 CDN 없이도 핵심 기능이 작동하도록 한다.

## 8. 구현 제외 범위

STAGE 02와 최초 포털 MVP에서는 다음을 구현하지 않는다.

- AI API 직접 호출
- GitHub 로그인
- 데이터베이스
- 실시간 교사 대시보드
- MCP 연결
- 자동 웹 검색
- 여러 사용자의 공동 편집

## 9. 완료 조건

- 7단계 전체를 한 프로젝트 데이터로 이동할 수 있다.
- 단계별 Context Packet을 생성·복사할 수 있다.
- State Snapshot으로 다음 단계 또는 새 채팅을 이어갈 수 있다.
- 테스트 3종과 수정 기록을 남길 수 있다.
- 전체 결과를 Markdown으로 내보낼 수 있다.
- GitHub Pages와 로컬 정적 실행에서 동일하게 작동한다.
