# LEVEL 1 포털 UX 수정안 R02

- 작성일: 2026-08-07
- 상태: SUPERSEDED_BY_R03
- 대상: `portal/modules/level-1-chat-agent/`

이 문서는 초기 사용자 피드백을 반영한 중간 UX안이다.

2026-08-08 추가 검토에서 다음 문제가 확인되었다.

- 왼쪽 데모가 제품 지향점을 보여주기에 매력이 부족함
- 6단계가 MVP 제작 과정을 지나치게 세분화해 입력이 반복됨
- '완성'이라는 표현이 실제 에이전트 제작 과정과 맞지 않음
- MVP 이후 수정·금지조건·검증·배포 판단이 더 중요함

따라서 이 문서의 6단계 UX안은 더 이상 최신 기준이 아니다.

최신 기준 문서:

`docs/03_platform_design/LEVEL1_AGENT_WORKFLOW_REVISION_20260808_R03.md`

1. MVP 제작

3. 사용자 검증 + AI 검증
4. 배포·데이터·기술 범위 판단

공통 프로젝트 생명주기 `DEFINE → COLLECT → STRUCTURE → BUILD → TEST → PUBLISH → IMPROVE` 자체는 변경하지 않는다.
