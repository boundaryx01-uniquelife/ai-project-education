## 확정 기준

- 1차 교육 대상은 채팅형 AI 기본 경험이 있는 교사와 교육 실무자이다.
- LEVEL은 도구가 아니라 자율성, 자료 연결, 배포 책임과 운영 지속성으로 구분한다.
- LEVEL 1은 3시간 채팅형 미니 에이전트이다.
- LEVEL 2는 4~6시간 GitHub Pages 기반 웹 에이전트이다.
- LEVEL 3은 8~12시간 자료 연결형 에이전트이다.
- LEVEL 4는 15시간 이상 운영형 장기 프로젝트이다.
- 모든 과정은 공통 7단계 생명주기와 산출물 사슬을 사용한다.
- 공통 역량은 8개로 구성하고 과정 기록과 검증을 우선 평가한다.
- Context Packet과 State Snapshot을 토큰 절약 및 프로젝트 인계의 표준으로 사용한다.
- 첫 시범 과정은 `근거 기반 수업 프로젝트 설계 미니 에이전트`로 한다.
