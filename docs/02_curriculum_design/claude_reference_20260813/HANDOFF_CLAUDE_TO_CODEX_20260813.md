## 1. 프로젝트 개요

**목표**: 학생들이 "AI 에이전트를 어떻게 만들어가는가"를 직접 예시학습으로 경험하는 수업자료 제작

**대상**: 초·중·고·성인 전연령 대응

**대표 예시 프로젝트**: 시험기간 플래너(`exam-planner.html`) — 실제 MVP 제작 → 수정 → 검증 과정을 수업 흐름으로 전환

**핵심 전제**: 외부 API/서버 없이 manual AI-in-the-loop 방식으로 무료 AI 챗봇을 활용해 전 과정을 완결한다.

## 2. 지금까지의 작업 이력

1. 시험기간 플래너 1차 MVP 지침 작성
2. 순수 HTML/CSS/JS 단일 파일 웹앱 MVP 제작
3. 범위 입력, 캘린더/일자별 탭, 정확한 시간표 등 사용성 수정
4. 단위당 학습시간 입력 제거 후 취약도 기반 자동 시간 배분으로 전환
5. 25/50/90분 집중 세션과 쉬는시간을 타임라인에 표시
6. 테스트일을 추가해 목표점수/채점결과 gap에 따라 복습 비중 조정
7. manual AI-in-the-loop 검증 구조 구현
8. GPT와 교차 검토하여 4단계 교육 구조를 LOCK

## 3. 시험기간 플래너 핵심

### 제약조건
- 외부 CDN/API/서버/DB 없음
- 순수 HTML+CSS+JS 단일 파일

### 입력
- 시험 시작일
- 학습 가능 시간대
- 집중 세션 길이 25/50/90분
- 과목별 범위와 취약도

### 처리
- 학습 가능 시간에서 세션/휴식 블록 계산
- 취약도 또는 검증 가중치 기준 과목별 세션 배분
- 학습 → 테스트 → 복습 페이즈 구성
- 테스트 점수 gap 또는 AI 검증 결과로 복습 가중치 재계산

### manual AI-in-the-loop
1. 앱에서 검증 프롬프트 생성
2. 외부 무료 AI에 복사
3. AI 답변 수신
4. 앱 또는 학습 기록에 반영
5. AI 미사용 시 내부 규칙 fallback

## 4. 확정된 교육 구조

1. MVP 제작
2. 수정·제약
3. 사용자 검증 + AI 검증
4. 다음 개발 판단

### 잠금 규칙
- MVP는 `입력 → 판단/규칙 → 출력`이 실제 작동해야 함
- 단순 입력 치환은 불인정
- 최소 1회는 실제 사용에서 발견한 제약/문제를 고친 수정이어야 함
- AI 검증을 실시하면 채택/기각과 이유 기록
- AI 검증을 생략하면 생략 이유와 대체 검증 기록
- 최종 산출물은 HTML + 수정기록 + 검증기록 + 다음 개발판단 패키지

### 유연 규칙
- 기본은 예시 변형 → 자유주제
- 자유주제 진입 시점은 연령/숙련도에 따라 조절
- 성인/숙련자는 처음부터 자유주제 가능

## 5. 다음 구현 방향

- 기존 LEVEL 1 포털을 위 4단계 기준으로 개별화 프로젝트에 맞게 개선
- 시험기간 플래너는 대표 예시로 활용하되 모든 학습자에게 강제하지 않음
- 최종 평가에서 결과물의 시각적 완성도보다 제작·수정·검증·판단 과정을 우선

## 6. 중요 우선순위 메모

Claude 원본 문서 일부에는 `AI 검증은 선택 사항`과 `AI 의견 채택/기각 이유 기록 필수`가 동시에 적힌 이전 문구가 남아 있다.

현재 최종 기준은 다음과 같다.

- AI 검증 실시 시: 채택/기각 및 이유 기록 필수
- AI 검증 생략 시: 생략 이유 + 대체 검증 내용 기록 필수
