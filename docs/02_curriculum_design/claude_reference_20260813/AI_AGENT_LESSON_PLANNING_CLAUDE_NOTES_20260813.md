# AI 에이전트 만들기 수업자료 기획 — Claude 논의 참고본

- Status: REFERENCE_ONLY
- 최종 기준은 `AI_AGENT_EDUCATION_FINAL_BASELINE_20260813.md`를 따른다.

## 배경 및 목적
- 학생들이 AI 에이전트를 어떻게 만들어가는지 예시학습으로 경험
- 대표 프로젝트: 시험기간 플래너
- 초·중·고·성인에 적용 가능한 공통 포맷

## 당시 확정·논의된 사항
1. 외부 CDN/API/서버 없이 브라우저에서 작동하는 단일 HTML 결과물
2. 시험기간 플래너의 학습시간 배분은 단위별 예상시간 입력보다 취약도 기반 자동 배분
3. 25/50/90분 집중 세션과 휴식시간을 타임라인에 표시
4. 테스트일에 목표점수·실제점수를 입력하고 gap에 따라 복습 비중 조정
5. AI 검증은 manual AI-in-the-loop 방식
6. AI 단계를 사용하지 않을 경우 내부 규칙 fallback 사용
7. 시험기간 플래너 완성 후 연령별 워크시트/지도안으로 확장

## 후속 검토 항목으로 논의했던 내용
- 연령별 난이도와 복사/붙여넣기 지원 수준
- 표준 차시와 학교급별 가변 운영
- 특정 AI 제품 고정 여부
- JSON 오류 복구 방식
- 점수 등 학습데이터 입력 시 개인정보 최소화
- AI 응답을 다시 검증하는 교육 메시지
- 예시 학습 후 자유주제로 전이하는 시점
- 결과물보다 제작·수정·검증 과정을 중심으로 평가할지 여부

이 항목들은 이후 GPT/Claude 교차검토를 거쳐 현재 최종 baseline의 4단계 구조와 잠금 규칙으로 정리되었다.
