# AI 프로젝트 교육 통합 프레임워크 결정 기록

- 작성일: 2026-08-05
- 상태: DECIDED

## D00-01

프로젝트의 정식 명칭은 `AI 프로젝트 교육 통합 프레임워크`로 한다.

## D00-02

정식 프로젝트 ID, 로컬 폴더와 GitHub 저장소 이름은 모두 `ai-project-education`으로 통일한다.

## D00-03

별도의 bootstrap, package 또는 임시 프로젝트 폴더를 두지 않는다.

## D00-04

모든 교육과정, 포털, Skill, 예시, 템플릿, 평가표와 운영문서는 하나의 GitHub 저장소에서 관리한다.

## D00-05

레벨별 교육자료는 독립 웹사이트나 별도 저장소로 분리하지 않고 단일 포털의 모듈로 확장한다.

## D00-06

로컬 작업과 초기화·검증·배포 도구는 Windows PowerShell을 기준으로 한다.

## D00-07

공식 원본은 GitHub `main` 브랜치이며, 정적 포털은 GitHub Pages로 배포한다.

## D00-08

프로젝트 추진은 STAGE 00부터 STAGE 07까지 단계별 문서, 결정 기록과 핸드오프로 관리한다.

## D00-09

GitHub 공식 소유 계정은 `boundaryx01-uniquelife`이며 기준 저장소는 `boundaryx01-uniquelife/ai-project-education`이다.

## D00-10

정규 학습 환경은 채팅형 AI를 기본으로 하고, 코딩 에이전트와 MCP는 교사용 제작 또는 확장 과정으로 둔다.

## D00-11

모든 교육 레벨은 `DEFINE → COLLECT → STRUCTURE → BUILD → TEST → PUBLISH → IMPROVE` 공통 생명주기를 사용한다.

## D00-12

STAGE 00 완료 후 다음 단계는 전체 교육과정과 역량 체계를 확정하는 STAGE 01로 한다.
