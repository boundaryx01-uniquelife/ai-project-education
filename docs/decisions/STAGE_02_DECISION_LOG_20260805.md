- 대상: LEVEL 1 시범 과정

## D02-01

첫 시범 과정의 정식 명칭은 `근거 기반 수업 프로젝트 설계 미니 에이전트`로 한다.

## D02-02

표준 수업 시간은 180분으로 하며 체험 15분, DEFINE 25분, COLLECT·STRUCTURE 30분, BUILD 45분, TEST 30분, PUBLISH 20분, IMPROVE 15분으로 구성한다.

## D02-03

수업의 최종 성과는 생성된 수업안 한 장이 아니라 문제 정의서, 자료 비교표, 에이전트 카드, 테스트 기록과 공유 패키지로 구성된 산출물 사슬이다.

## D02-04

기준 예시는 초등학교 고학년 과학 탐구 수업 설계로 한다. 학습자는 교과, 학년, 문제와 출력 형식을 변경한다.

## D02-05

학습 자유도는 공통 구조 70%, 선택 항목 20%, 자유 설계 10%를 유지한다.

## D02-06

근거 자료는 3건 이상으로 하며 출처, 작성 주체, 작성일, 원문 위치와 제한을 기록한다.

## D02-07

에이전트는 최소 4단계의 처리 과정, 입력·출력 형식, 검증 기준과 중단 조건을 가져야 한다.

## D02-08

모든 학습자는 정상·경계·실패 테스트를 각각 1건 이상 수행하고 수정 전후를 기록한다.

## D02-09

가짜 출처, 개인정보와 근거가 없는 입력에 대해 에이전트가 중단하거나 경고하지 못하면 완료로 인정하지 않는다.

## D02-10

평가는 8개 영역 24점 루브릭과 필수 게이트를 함께 사용한다. 18점 이상이며 모든 필수 게이트를 통과해야 완료다.

## D02-11

통합 포털은 단계 안내, 입력 양식, Context Packet 조립, State Snapshot, 테스트 기록과 Markdown 내보내기를 담당한다.

## D02-12

최초 포털 모듈은 서버, 로그인과 AI API 호출 없이 정적 웹과 브라우저 localStorage로 작동한다.

## D02-13

교사용 모드는 참가자 데이터를 수집하는 대시보드가 아니라 단계별 진행 질문, 시간 안내와 안전 경고를 제공한다.

## D02-14

인터넷 검색이 불가능한 수업을 위해 확인 가능한 기준 자료 묶음을 교사가 제공한다.

## D02-15

학습자가 AI에 보내는 정보는 단계별 Context Packet으로 제한하고, 완료 단계는 State Snapshot으로 이어간다.

## D02-16
