# STAGE 03 결정 기록

- 작성일: 2026-08-07
- UX 개정일: 2026-08-08
- 상태: `PROPOSED_FOR_APPROVAL`

## D03-01

LEVEL 1 포털 MVP 구현 경로는 `portal/modules/level-1-chat-agent/`로 고정한다.

## D03-02

MVP 기술은 HTML5, CSS, Vanilla JavaScript, localStorage로 유지한다.

## D03-03

LEVEL 1은 `인트로`와 `따라하기 워크숍`을 분리한다.

- `index.html`: 프로젝트 설명과 대상 선택
- `workshop.html?audience=...`: 실제 제작 활동

## D03-04

대상별 기본 따라하기 예시는 다음으로 고정한다.

- 초등: 용돈지킴이
- 중·고등: 시험기간 플래너
- 성인: 여행 일정 에이전트

## D03-05

워크숍 작업 화면은 `왼쪽 SAMPLE / 오른쪽 FOLLOW` 2열을 기본으로 한다. 필수 작업 외 설명은 접힌 참고 영역으로 보낸다.

## D03-06

워크숍 시작 시 선택 방식을 다시 묻지 않는다. 인트로에서 고른 예시를 그대로 따라 만들고, 개별화·커스텀은 후속 단계로 둔다.

## D03-07

학습자 화면은 내부 생명주기를 6개 제작 화면으로 단순화한다.

1. 목표
2. 판단정보
3. 작동순서
4. 에이전트 생성
5. AI 테스트
6. 완성·개선

DEFINE → COLLECT → STRUCTURE → BUILD → TEST → PUBLISH → IMPROVE 기준 자체는 유지한다.

## D03-08

각 제작 화면에서 `웹페이지에서 할 일`과 `생성형 AI에서 할 일`을 서로 다른 강조 블록으로 명확히 구분한다.

## D03-09

완성 모습을 설명문으로만 보여주지 않는다. 왼쪽 SAMPLE 영역에 대상별로 직접 입력하고 버튼을 눌러 결과 형태를 확인할 수 있는 미니 데모를 제공한다.

## D03-10

AI와의 상호작용은 별도 작업 탭으로 분리하지 않는다. 현재 단계에서 자동 조립된 AI 요청문을 복사해 외부 생성형 AI에 붙여넣도록 한다.

## D03-11

최종 단계에서는 재사용 가능한 에이전트 지침을 바로 복사할 수 있고, 테스트 기록과 개선 내용을 포함한 Markdown 패키지도 저장할 수 있게 한다.

## D03-12

완료 게이트는 최소 구조만 자동 판정하며 교육적 품질은 사람이 판단한다.

## D03-13

AI API, 로그인, 데이터베이스, MCP, 사용자 추적과 LEVEL 2 기능은 STAGE 03 MVP에서 제외한다.

## D03-14

현재 구현 후보는 사용자 UX 피드백을 반영한 상태이며, 로컬 브라우저 검토와 GitHub Pages 배포 검증 전에는 STAGE 03을 COMPLETE로 확정하지 않는다.
