# AI 프로젝트 교육 통합 프레임워크 프로젝트 헌장

- 작성일: 2026-08-05
- 상태: DECIDED

## 목적

교육자가 AI를 이용해 자료 수집, 분석, 구조화, 제작, 검증, 배포와 개선까지 수행하는 실제 프로젝트형 교육을 설계하고 운영할 수 있는 통합 체계를 만든다.

## 해결하려는 문제

- 단순 프롬프트 체험과 일회성 바이브 코딩에 머무는 수업
- 수업 시수와 학습자 수준에 맞는 단계 체계 부재
- 교육과정, 실습 웹페이지, 예시와 평가가 서로 분리되는 문제
- 특정 AI 플랫폼의 기능과 UI에 과도하게 종속되는 문제
- 토큰, API 키, 개인정보와 배포 환경을 고려하지 않은 설계

## 포함 범위

- LEVEL 1부터 LEVEL 4까지의 단계형 교육과정
- 교사용 진행안과 학습자용 실습자료
- 단일 교육 웹포털
- 공통 프로젝트 생명주기와 컨텍스트 패킷
- 예시, 템플릿, 평가 루브릭
- 범용 Skill과 플랫폼별 어댑터
- GitHub 저장, Pages 배포와 Release 운영
- 파일·공개 데이터·MCP 확장 과정

## 제외 범위

- 특정 생성형 AI 서비스의 기능 교육만을 위한 과정
- API 키와 유료 서비스가 없으면 진행할 수 없는 기본 과정
- 교육 목적과 무관한 범용 개발 플랫폼 구축
- 학생 개인정보를 저장하는 운영 시스템
- 완전 자율형 에이전트를 모든 과정의 필수 결과물로 요구하는 방식

## 역할

### GPT

교육 체계 설계, 문서화, 검증 기준, 수업자료와 프로젝트 기록을 담당한다.

### Codex

승인된 웹포털, 템플릿, 검사 도구와 배포 자동화를 구현한다.

### Claude Code

다중 파일 분석, 장기 저장소 개선과 고급 과정의 선택형 구현을 담당한다.

### Antigravity

교육용 시각 프로토타입과 브라우저 상호작용 시연에 제한적으로 사용한다.

## 운영 원칙

- GitHub 저장소를 단일 원본으로 사용한다.
- PowerShell을 로컬 작업 기준으로 사용한다.
- 설계, 구현, 검증과 승인을 분리한다.
- 각 단계는 결정 기록과 다음 단계 핸드오프를 남긴다.
- 학습자가 AI 결과를 검토하고 수정하는 과정을 필수로 둔다.

## 1차 성공 기준

- 3시간 LEVEL 1 과정이 실제 수업 가능한 상태로 완성된다.
- 학습자가 서로 다른 결과물을 만든다.
- 학습자가 프롬프트 문구가 아니라 입력, 처리 단계, 출력과 검증 구조를 설명한다.
- 교육 웹포털이 온라인과 로컬에서 작동한다.
- 수업 결과와 개선점을 GitHub에 축적할 수 있다.
