# LEVEL 1 미니 에이전트 평가 루브릭

- 작성일: 2026-08-05
- 대상 과정: 근거 기반 수업 프로젝트 설계 미니 에이전트
- 평가 목적: 결과 문장보다 프로젝트 구조와 검증 과정을 평가한다.

## 평가 방식

- 각 영역은 0~3점이다.
- 총점은 24점이다.
- 18점 이상이면서 필수 게이트를 모두 통과해야 완료로 인정한다.
- 점수만으로 통과시킬 수 없는 필수 게이트가 별도로 있다.

## 루브릭

| 영역 | 3점 | 2점 | 1점 | 0점 |
|---|---|---|---|---|
| 문제 정의 | 사용자·장면·문제·제약·성공 조건이 구체적 | 한 항목이 모호함 | 여러 항목이 넓거나 추상적 | 실제 문제 정의가 없음 |
| 자료와 출처 | 확인 가능한 자료 3건 이상, 출처·작성일·제한 기록 | 자료 3건이나 일부 메타데이터 부족 | 자료가 1~2건 또는 출처가 불명확 | 출처 기록 없음 |
| 자료 분석 | 사실·적용·제한·추론을 구분 | 대부분 구분하나 일부 혼합 | 단순 요약 위주 | 자료를 실제로 사용하지 않음 |

| 공유와 재사용 | 설명 없이 사용할 패키지, 버전·제한 포함 | 사용 가능하나 안내 일부 부족 | 작성자 설명이 필요 | 재사용할 형태가 아님 |

## 필수 게이트

다음 중 하나라도 실패하면 총점과 관계없이 `REVISE`다.

1. 실제 학생 개인정보를 입력하거나 공유했다.
2. 존재하지 않거나 확인하지 못한 출처를 사실처럼 사용했다.
3. 정상 테스트만 하고 경계·실패 테스트를 생략했다.
4. 작업 단계 없이 한 번의 생성 프롬프트만 제출했다.
5. 다른 사용자가 사용할 수 있는 입력 방법이 없다.
6. AI 결과를 교사의 최종 판단으로 그대로 확정했다.

## 판정

- 22~24점: `READY_TO_REUSE`
- 18~21점: `COMPLETE`
- 13~17점: `REVISE`
- 0~12점: `REBUILD`

필수 게이트 실패 시 판정은 항상 `REVISE` 또는 `REBUILD`다.

## 형성평가 체크포인트

### DEFINE 이후

- 문제를 한 번의 사용 장면으로 좁혔는가?
- 성공 조건을 관찰할 수 있는가?

### STRUCTURE 이후

- 각 단계의 결과가 다음 단계 입력으로 사용되는가?
- 자료가 어떤 판단에 사용되는가?

### BUILD 이후

- 입력이 부족할 때 에이전트가 멈추는가?
- 결과 형식이 사용 목적과 맞는가?

### TEST 이후

- 실패를 숨기지 않고 기록했는가?
- 수정 전후 차이가 남아 있는가?

## 동료 피드백 문장

- 가장 안정적으로 작동한 부분은 `___`이다.
- 실제 사용 전 반드시 고쳐야 할 부분은 `___`이다.
