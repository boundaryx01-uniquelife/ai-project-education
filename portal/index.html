TWO-WINDOW PRACTICE

한쪽에서는 만들고,
다른 한쪽에서는 묻습니다.

학습 페이지가 AI를 대신하지 않습니다. 매 단계마다 학생이 AI에게 보낼 요청을 만들고, 결과를 확인한 뒤, 한 가지 문제를 직접 고칩니다.

  1. 01오늘 만들 한 가지예시를 보고 목표를 정한다.
  2. 02AI에 요청하기복사 가능한 프롬프트로 만든다.
  3. 03실행해 보기브라우저·휴대폰에서 직접 확인한다.
  4. 04한 점만 고치기관찰한 문제를 핀포인트로 수정한다.

PROJECT RULE

데이터와 AI는
기능이면서 책임입니다.

Level 3부터는 출처와 갱신 시각을 표시합니다. Level 4부터는 API 키를 서버에서 보호하고, 비용·개인정보·위험한 답변을 함께 관리합니다. 텔레그램 알림봇은 토큰과 수신자 권한이 필요한 심화 안내 자료로만 다룹니다.
