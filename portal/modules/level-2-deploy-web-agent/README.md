# LEVEL 2 배포형 웹 도구 워크숍

- 위치: `portal/modules/level-2-deploy-web-agent/`
- 권장 시간: 4~6시간
- 기술: HTML, CSS, Vanilla JavaScript, localStorage, GitHub Pages
- 외부 패키지/CDN: 없음

## 과정 목적

사용자가 실제로 조작하는 단일 HTML MVP를 만들고, 행동 규칙을 수정·검증·재검증한 뒤 공유 가능한 정적 웹 도구로 배포할 범위를 결정한다.

## 완성 결과물

- 실행 가능한 웹 도구 HTML
- 수정·검증·재검증 기록
- 사용 안내와 알려진 제한
- GitHub Pages 배포 주소와 배포 후 테스트 기록

## 과정 경계

- 이 모듈은 독립적인 LEVEL 2 과정이며 LEVEL 1 이수가 필수는 아니다.
- API 키, 서버, 데이터베이스, 로그인, 자동 외부 웹 접근은 포함하지 않는다.
- 실제 자료 연결과 출처·최신성 처리는 LEVEL 3의 별도 과정 범위다.
