# LEVEL 2 배포형 웹 에이전트 시작 작업대

LEVEL 2는 독립적으로 운영하는 4~6시간 배포형 웹 에이전트 과정이다. 이 작업대에서 프로젝트 브리프, 사용자 흐름, 화면별 입력·출력, 규칙·제한과 배포 검증 범위를 정리한다.

## 현재 범위

- 브라우저 localStorage 저장
- LEVEL 2 구현용 컨텍스트 패킷과 상태 스냅샷 다운로드
- 정적 웹, API 키 없음, 외부 API·DB 구현 없음

## 다음 구현 작업

1. 인계된 요구사항을 실제 배포형 웹 도구의 화면·입력·출력으로 구현한다.
2. 정상·경계·오류·새로고침 테스트 기록을 추가한다.
3. GitHub Pages 배포 주소에서 사용 안내와 제한을 검증한다.
