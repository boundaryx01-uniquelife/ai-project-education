# LEVEL 1 자료 기반 단일 챗봇

## 과정 목적

3차시 동안 완성된 진로 철학자 챗봇을 따라 해 보고, 빈 개인 실습에서 자기 주제의 단일 HTML 챗봇을 만든다.

1. 자료와 반복 질문을 확인·조정한다.
2. 질문 유형별 응답 카드를 만든다.
3. 실제 브라우저 MVP를 대화해 보고 단일 HTML 파일로 내려받는다.

## 학습 방식

- 따라하기 실습은 진로·철학자 대화봇의 자료, 질문, 응답 카드가 미리 채워져 있다.
- 학습자는 필요한 문장을 더하거나 지우며 카드와 자료 범위를 이해한다.
- 개인 실습은 빈 카드 한 장에서 시작한다.
- 외부 생성형 AI는 자료를 정리하고 응답 카드를 제안하거나 더 풍부한 단일 HTML을 생성하는 보조 도구로 사용한다.

## 완성 결과물

- 자료 목록과 답변 범위
- 키워드·답변·다음 질문으로 이루어진 응답 카드
- API 없이 실행되는 단일 HTML 챗봇

## 과정 경계

- 이 챗봇은 내장한 응답 카드의 키워드로 답한다. 자유 생성형 AI가 아니다.
- 자료에 없는 질문에는 답을 꾸며내지 않고 탐색 질문을 제시한다.
- API, 외부 검색, 서버, 데이터베이스는 사용하지 않는다.
