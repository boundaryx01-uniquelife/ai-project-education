# LEVEL 1 대화형 미니 에이전트

## 과정 목적

3시간 동안 먼저 대화봇 주제의 적합성과 신뢰 가능한 자료 확보 가능성을 판단한다. 그 뒤 대화 역할, 사용할 근거 범위, 금지·재질문 규칙을 설계하고 외부 채팅 AI에서 실제 질문으로 검증한다.

## 시작 판단 게이트

프롬프트를 만들기 전에 다음을 모두 기록·확인한다.

- 반복해서 나올 질문 유형과 사용 목적
- 답할 수 있는 범위와 답하지 않을 범위
- 작성·발행 주체, 위치, 날짜·판본, 사용 이유가 적힌 신뢰 자료 2건 이상
- 자료 사용 조건과 필요한 발췌를 프롬프트에 제공할 수 있는지

화면의 **적합성 판단 프롬프트**를 외부 AI에 보내 주제·범위·자료 신뢰도·위험을 검토한다. AI의 답변을 붙여넣고, 학습자가 원문 자료를 직접 확인한 뒤 `적합 — 이 주제로 진행`과 판단 이유를 기록하는 것을 권장한다. 현재는 테스트 운영 중이므로 미완료·`보완 필요`·`부적합` 상태도 다음 단계 이동을 막지 않는다. 정식 운영 때는 `TEST_MODE`를 `false`로 바꾸면 다시 단계 이동을 제한한다.

이 과정에서 자료를 자동 검색하거나 연결하지는 않는다. 실제 자료 연결·출처 자동 표시는 LEVEL 3의 범위다.

## 완성 결과물

- 재사용 가능한 대화 프롬프트
- 역할·근거·금지 규칙이 적힌 대화봇 카드
- 실제 질문 1건 이상과 검증 기록
- LEVEL 1 대화봇 패키지 Markdown

## MVP 미리보기

- 3단계에서는 설정한 역할·자료 범위·금지 규칙을 보여주는 로컬 규칙 기반 대화 미리보기를 확인한다. 이는 AI 답변 생성 기능이 아니다.
- 4단계에서는 외부 AI에서 시험한 실제 질문과 응답을 대화 형태로 다시 보고, 규칙 준수 여부를 검증한다.

## 보완과 재검증

각 단계의 **보완 필요** 판단은 현재 입력을 삭제하지 않는다. 5단계 **핀포인트 보완 계획** 페이지에서 이전 결과를 읽기 전용으로 보고, 사용자는 `고칠 한 가지`와 `원하는 결과`만 정한다. 이 두 항목을 반영한 AI 프롬프트로 구체적 수정 문장과 재검증 질문을 요청한다. 계획을 확정하면 이력이 남고 지정한 수정 위치로 이동한다. 4단계에서 시작한 계획은 당시 시험 질문·응답·발견 문제도 검증 버전으로 보관한다.

## 과정 경계

- 이 모듈은 ChatGPT·Claude 등의 API를 호출하지 않는다.
- AI 응답은 학습자가 외부 채팅 AI에서 직접 받아 검토한다.
- 실제 문서 업로드·검색·출처 자동 연결은 LEVEL 3 자료 연결형 에이전트 과정의 범위다.
