만드는 방식 선택
이 활동에서 지킬 3가지 원칙 보기
단계형 프로젝트의 핵심
목표 확정에이전트가 해결할 문제를 한 장면으로 좁힙니다.
한 문장 점검 “이 에이전트는 누가, 어떤 상황에서, 어떤 문제를 해결해 어떤 결과를 얻게 한다.”가 말이 되면 다음으로 갑니다.
판단 기준·정보 넣기에이전트가 마음대로 추측하지 않도록 실제 판단에 필요한 정보나 규칙을 최소 3개 넣습니다.
웹 검색 자료만 ‘근거’인 것은 아닙니다. 현재 용돈, 시험 날짜, 여행 예산처럼 사용자가 제공하는 사실과 명시적인 판단 규칙도 중요한 근거입니다.
작동 방식 만들기사용자 입력을 받은 뒤 에이전트가 어떤 순서로 확인하고 비교하고 판단할지 정합니다.
에이전트가 처리할 순서 4~6개

각 칸은 실제 에이전트가 수행할 한 가지 행동입니다.

여기서 실제 에이전트가 만들어집니다.앞에서 정한 목표·판단 기준·작동 순서를 하나의 실행 가능한 에이전트 카드로 자동 조립합니다.
AI와 실제 시험하기아래 입력을 AI에 보내고, 나온 답을 그대로 기록해 에이전트가 어디서 흔들리는지 찾습니다.
완성본 받기목표, 판단 기준, 에이전트 카드, 테스트 기록을 한 파일로 묶습니다.
한 번 고쳐서 진짜 내 것으로 만들기테스트와 동료 의견 중 하나를 선택해 수정 전후를 남깁니다.
