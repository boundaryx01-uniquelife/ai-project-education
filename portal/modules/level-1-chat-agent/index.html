1. CHECK FIRST

이 주제가 대화봇으로 적합한가?

대화봇은 모든 질문에 답하는 도구가 아닙니다. 반복해서 나올 질문 유형이 있고, 답변 범위를 제한할 수 있으며, 신뢰 가능한 자료를 확보할 수 있을 때만 시작합니다.

AI에게 적합성 판단을 요청하세요.

아래 프롬프트를 ChatGPT·Claude 등에 보내고, AI 판단은 참고로만 사용합니다. 자료의 실제 발행 주체·날짜·사용 조건은 원문에서 직접 확인하세요.

판단 근거를 찾는 방법
  1. 교육기관·공공기관·도서관·원저작자·공식 출판사처럼 작성 주체가 확인되는 자료부터 찾습니다.
  2. 발행일·판본·원문 위치·사용 조건을 기록합니다.
  3. 서로 다른 두 자료가 같은 핵심 개념을 뒷받침하는지 비교합니다.
  4. 자료에 없는 사실·인용은 챗봇의 답변 범위에서 제외합니다.
