시작 전 3가지 약속 확인
단계형 프로젝트의 핵심
목표 확정에이전트가 해결할 문제를 한 장면으로 좁힙니다.
한 문장 점검 “이 에이전트는 누가, 어떤 상황에서, 어떤 문제를 해결해 어떤 결과를 얻게 한다.”가 말이 되면 다음으로 갑니다.
근거 넣기에이전트가 마음대로 꾸며내지 않도록 확인 가능한 자료 3건을 넣습니다.
수업에서는 교사가 제공한 자료 묶음 사용을 권장합니다. 처음부터 웹 검색까지 시키면 ‘에이전트 만들기’보다 자료 찾기에 시간이 더 걸릴 수 있습니다.
작동 방식 만들기사용자 입력을 받은 뒤 에이전트가 어떤 순서로 생각하고 검사할지 정합니다.
에이전트가 처리할 순서 4~6개

각 칸은 실제 에이전트가 수행할 한 가지 행동입니다.

여기서 실제 에이전트가 만들어집니다.앞에서 정한 목표·근거·작동 순서를 하나의 실행 가능한 에이전트 카드로 자동 조립합니다.
AI와 실제 시험하기아래 입력을 AI에 보내고, 나온 답을 그대로 기록해 에이전트가 어디서 흔들리는지 찾습니다.
완성본 받기목표, 근거, 에이전트 카드, 테스트 기록을 한 파일로 묶습니다.
한 번 고쳐서 진짜 내 것으로 만들기테스트와 동료 의견 중 하나를 선택해 수정 전후를 남깁니다.
