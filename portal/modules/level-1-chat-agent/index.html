핵심

이 챗봇은 내장한 자료·질문 카드 안에서만 답합니다. 자료에 없는 질문은 답을 꾸며내지 않고 탐색 질문으로 돌려줍니다.

LESSON 1 · SEE & ADJUST

자료와 질문을 확인합니다.

따라하기 실습은 이미 채워져 있습니다. 처음부터 길게 작성하지 말고, 필요한 문장만 더하거나 지우세요.

필요하면 AI에게 자료·응답 카드 생성을 요청하세요.


LESSON 2 · ANSWER CARDS
반복 질문에 답할 카드를 만듭니다.
카드 하나는 질문 유형 하나만 다룹니다. 따라하기 카드에서 문장을 다듬거나, 개인 실습에서 직접 추가하세요.


LESSON 3 · RUN THE MVP
실제 자료 기반 챗봇을 대화해 봅니다.
카드의 키워드와 일치하는 질문에 답합니다. 일치하지 않으면 범위를 밝히고 탐색 질문을 제시합니다.
