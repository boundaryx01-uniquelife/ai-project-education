FAQ와 수업 전 확인 사항

API 키를 GitHub Pages에 넣으면 왜 안 되나요?

정적 사이트의 코드와 네트워크 요청은 누구나 확인할 수 있어 키가 유출됩니다. 키는 교사 또는 운영자가 관리하는 서버 환경에만 둡니다.

부산버스 API가 멈추면 앱은 실패인가요?

아닙니다. 외부 데이터는 실패할 수 있습니다. 마지막 정상 정보, 연결 실패 안내, 다시 시도 버튼을 만드는 것도 이 레벨의 핵심입니다.

텔레그램 알림도 만들 수 있나요?

기본 실습이 아니라 심화 안내 자료입니다. 토큰, 수신 동의, 개인정보, 지속 실행 환경이 필요해 Level 4의 교사 관리 프로젝트에서만 선택적으로 다룹니다.
