LEVEL 3 · API REFERENCE GUIDE

철학자 API는
어떻게 작동할까?

이 자료는 API 연결 실습이 아닙니다. 철학자 원문을 근거로 답변하는 서버형 AI의 구조, 사용 범위, 주의사항을 이해하는 읽기 자료입니다.

읽기·토의 자료API 키 입력 없음외부 연결 없음

1. 어떤 구조인가요?

사용자의 질문→웹 서비스→서버의 철학자 원문 검색→AI 답변 생성→답변 + 참고 원문

웹페이지는 질문을 보여 주는 창이고, 실제 검색과 AI 답변 생성은 서버에서 이루어집니다. 그래서 웹페이지 안에 비밀키를 넣으면 안 됩니다.

2. 학습자에게 어떤 점이 좋은가요?

1

근거 보기

답변만 읽는 대신, 어떤 철학자 원문이 참고되었는지 함께 확인할 수 있습니다.

2

대화 맥락

이전 대화를 필요한 범위에서 참고하면 한 문답씩 끊기지 않는 대화를 설계할 수 있습니다.

3

한계 알기

원문을 검색해도 AI가 만든 답변 전체가 정확하거나 공정하다고 보장되지는 않습니다.

4

사람의 판단

중요한 진로·마음 건강·법률·의학 판단은 AI가 아니라 사람과 상의해야 합니다.

3. 사용할 때 주의할 점

비밀키·개인정보·근거를 함께 점검합니다.

  • API 키와 관리자 비밀번호는 서버 환경변수에만 보관하며, HTML·GitHub·채팅에 적지 않습니다.
  • 실명, 연락처, 건강·위기 정보 등 민감한 개인정보를 질문으로 보내지 않습니다.
  • 답변과 참고 원문을 구분하고, 원문의 날짜·맥락·사용 조건을 확인합니다.
  • 철학자 말투는 생각을 돕는 방식일 뿐 심리치료나 진로 결정을 대신하지 않습니다.
  • 서버가 멈추거나 자료가 오래되었을 때의 안내와 책임자는 운영자가 정합니다.

4. 자주 묻는 질문

API 키는 왜 보이지 않아야 하나요?

키가 웹페이지에 있으면 방문자가 복사해 비용 발생이나 데이터 접근에 악용할 수 있습니다.

참고 원문이 있으면 답변은 맞나요?

아닙니다. AI의 해석이 섞일 수 있으므로 원문과 답변을 구분해 읽어야 합니다.

API 오류가 나면 어떻게 하나요?

사용자에게 재시도나 다른 활동을 안내하고, 운영자가 오류 기록을 확인합니다.

이 API로 상담해도 되나요?

생각을 정리하는 대화는 가능하지만 위기·치료·전문 판단이 필요한 상황은 교사·보호자·전문기관의 도움을 받아야 합니다.

읽고 난 뒤 확인
