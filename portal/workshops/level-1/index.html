오늘의 결과물index.html · manifest.webmanifest · service-worker.js · icon.svg외부 API·로그인·DB 없이, 브라우저 저장만 사용합니다.

STEP 01

먼저, 만들 앱을 고릅니다.

세 예시는 이미 채워져 있습니다. 마음에 들지 않는 부분은 고르고 난 뒤 한 가지씩 바꿉니다.

예시 대신 내 아이디어로 시작하기

다음 행동: 선택한 예시가 마음에 드는지 확인하고 AI 요청문을 만듭니다.

STEP 02

AI에게 ‘파일 묶음’을 요청합니다.

아래 요청을 복사해 외부 AI에 보냅니다. 설명이나 일부 코드가 아니라, 파일별 전체 코드를 달라고 명시하는 것이 중요합니다.

AI에 보낼 요청
AI가 설명만 하고 코드를 안 주면?
“설명은 빼고, 바뀐 파일의 전체 코드를 파일명별로 다시 출력해줘. Markdown 코드 블록을 사용해줘.”라고 추가로 요청합니다.
AI 창에서 확인
  1. 파일이 4개인가?
  2. 외부 API·CDN·로그인이 없는가?
  3. 휴대폰 화면을 고려했는가?
  4. localStorage가 있는가?
프롬프트 해설 보기 ↗

      
다음 행동: AI가 준 코드를 파일 칸에 붙여 넣습니다.

다음 행동: 입력·추가·완료 표시가 실제로 바뀌는지 확인합니다.

    


    

      
STEP 04
한 가지씩, 정확하게 보완합니다.
첫 실행이 됐다면 한 번에 크게 바꾸지 않습니다. 같은 AI 대화를 이어서 아래 요청을 보내고, 받은 index.html 전체만 바꿔 넣어 다시 실행합니다.

      

      
      
      
AI에 보낼 ‘한 가지 보완’ 요청

      
보완할 때의 약속“디자인도, 알림도, 로그인도 모두 추가해줘”라고 묶지 않습니다. 기능 하나를 요청하고, 실행·확인한 뒤 다음 기능으로 넘어갑니다.

      
다음 행동: 바뀐 index.html 전체를 넣고 미리보기를 다시 확인합니다.

    


    

      
STEP 05
테스트하고, PWA 파일로 가져갑니다.
단순히 화면이 보이는 것과 실제로 쓸 수 있는 것은 다릅니다. 아래 세 가지를 해 보고, 파일을 내려받아 GitHub Pages에 배포합니다.

      

      
PWA PACKAGE
파일 4개를 내려받기
같은 폴더에 저장한 뒤 GitHub 저장소에 올립니다. `icon.svg`는 나중에 PNG 아이콘으로 바꿔도 됩니다.

      
1GitHub에서 새 저장소를 만들고 파일 4개를 올립니다.
2Settings → Pages에서 배포를 켭니다.
3휴대폰 Chrome에서 배포 주소를 열고 ‘홈 화면에 추가’를 확인합니다.

      
여기까지 왔다면 Level 1의 최소 MVP를 완성했습니다.이제 한 가지 기능만 더 추가하거나, 같은 흐름으로 나만의 생활 앱을 만드세요. 기능을 한꺼번에 늘리지는 않습니다.
