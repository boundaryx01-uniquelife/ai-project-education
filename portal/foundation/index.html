20~40 MINUTES · BEFORE YOU BUILD

만들기 전에,
AI가 맡을 일부터 정합니다.

AI 프로젝트를 시작하기 위한 첫 수업입니다. 어려운 기술보다 ‘AI가 어디까지 판단하고 행동하는가’를 먼저 구별합니다.

0~8 MINUTES

AI가 들어가면
모두 Agent일까?

다섯 단계를 구분하는 기준은 하나입니다.

“AI가 어디까지 스스로 판단하고 행동하는가?”
01일반 웹앱

정해진 규칙과 버튼대로 작동한다.

02AI 웹앱

AI가 질문에 답하거나 내용을 만든다.

03AI Workflow

미리 정한 순서로 AI를 여러 번 쓴다.

04AI Agent

목표와 상황을 보고 필요한 일을 판단한다.

05Agentic AI

결과를 확인하고 다음 계획을 다시 고친다.

8~14 MINUTES · MINI ACTIVITY

이 사례는
어느 단계일까?

정답을 외우지 말고, AI가 무엇을 했는지 생각해 보세요.

14~18 MINUTES

챗봇은 대답하고,
Agent는 일을 처리합니다.

CHATBOT

“시험 공부는 어떻게 해?”

공부 방법을 설명한다.

질문 → 답변
AGENT

“3주 남았고 수학이 부족해. 계획을 만들어 줘.”

상태 확인 → 부족 과목 판단 → 시간 배분 → 날짜별 계획

목표 → 판단·처리 → 결과

REMEMBER

“답을 했는가?”가 아니라
“목표를 받아 일을 처리했는가?”Agent가 챗봇보다 무조건 더 똑똑하다는 뜻은 아닙니다. 맡는 일이 다릅니다.

18~24 MINUTES

프로젝트에서 자주 만나는
세 단어를 나눠 봅시다.

MVP

작게 시작하는 방법

핵심 기능만 먼저 만들어 실제로 쓸 수 있는지 확인하는 첫 제품

만들기 → 사용 → 문제 발견 → 수정
AGENT

AI의 일하는 방식

사용자의 목표와 상황을 보고 여러 단계를 거쳐 일을 처리하는 AI

목표 → 판단 → 처리 → 결과
PWA

웹앱을 사용하는 방식

웹으로 만들지만 휴대폰·컴퓨터에서 앱처럼 설치해 사용하는 웹앱

웹으로 만들고, 앱처럼 사용

세 단어는 함께 등장할 수 있지만 하나의 기술 이름이 아닙니다.

24~32 MINUTES · EXTENSION

AI에게는
무엇을 알려 줘야 할까?

좋은 프롬프트는 길이가 아니라, 필요한 정보가 분명한지에 달려 있습니다.

목표입력결과제약
모호한 요청

시험 플래너 앱 만들어 줘.

바꾼 요청

고등학생이 과목과 시험일을 입력하면 오늘 할 일 세 개를 보여 주는 휴대폰용 웹앱을 만들어 줘. 로그인·API·DB는 넣지 마.

SAFE START

AI를 쓸 때
확인할 세 가지

  1. 사실 중요한 정보는 출처와 날짜를 다시 확인한다.
  2. 개인정보 연락처·비밀번호·친구 정보·API 키를 넣지 않는다.
  3. 사람의 판단 AI 결과를 읽고 고친 뒤 사용한다.
