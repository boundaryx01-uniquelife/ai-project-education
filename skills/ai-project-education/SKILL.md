# AI Project Education

Use this skill when designing or running education that uses AI to collect, analyze, build, validate, and publish real project outcomes.

## Lifecycle

1. DEFINE
2. COLLECT
3. STRUCTURE
4. BUILD
5. TEST
6. PUBLISH
7. IMPROVE

## Rules

- Do not reduce the activity to one-shot prompting.
- Leave a visible artifact at every stage.
- Use chat-based AI as the learner default.
- Treat coding agents and MCP as optional extensions.
- Reuse shared templates, examples, and rubrics.
- Validate before publishing.
