# AI 프로젝트 시작 전: 1차시 수업 자료

## 수업 개요

| 항목 | 내용 |
| --- | --- |
| 대상 | AI 프로젝트를 처음 시작하는 초·중·고 학생 |
| 권장 시간 | 기본 20분, 활동 확장 40분 |
| 수업 목표 | AI가 맡는 일의 범위, 챗봇·Workflow·Agent, MVP·PWA, 안전한 AI 활용의 기본을 구별한다. |
| 다음 활동 | Level 1~4 중 자신의 프로젝트 수준에 맞는 실습을 선택한다. |

## 학생이 가져갈 핵심 문장

1. **AI가 어디까지 스스로 판단하고 행동하는가?**를 보면 AI 활용 수준을 구별할 수 있다.
2. **챗봇은 대답하는 AI, Agent는 일을 맡아서 처리하는 AI**다.
3. **MVP는 작게 시작하는 방법, Agent는 AI의 일하는 방식, PWA는 앱을 사용하는 방식**이다.
4. AI가 만든 답은 바로 믿지 않고, **출처·사실·개인정보**를 확인한다.

### 시작 질문

학생에게 아래 사례를 빠르게 보여 준다.

```text
시험 날짜와 과목을 입력하면 공부 시간을 계산해 주는 앱
```

질문한다.

> 이 앱은 AI Agent일까, 아니면 정해진 규칙대로 작동하는 웹앱일까?

정답을 바로 말하지 않는다. “AI가 무엇을 판단했는가?”를 먼저 묻는다.

## 꼭 알아둘 기본 개념

### AI와 생성형 AI

- **AI:** 입력을 바탕으로 분류, 예측, 추천, 생성 같은 일을 하는 기술을 넓게 부르는 말
- **생성형 AI:** 문장, 그림, 코드처럼 새로운 결과를 만들어 내는 AI

학생 표현으로는 이렇게 기억한다.

> AI는 정보를 다루는 기술이고, 생성형 AI는 결과를 만들어 주는 AI다.

### Prompt(프롬프트)

AI에게 보내는 요청문이다. 좋은 프롬프트는 길이가 아니라 필요한 정보가 분명한지에 달려 있다.

```text
[목표] 무엇을 만들거나 해결할까?
[입력] AI가 알아야 할 정보는 무엇일까?
[결과] 어떤 형태의 답이 필요할까?
[제약] 하지 말아야 할 일과 확인할 기준은 무엇일까?
```

### Input과 Output

- **Input(입력):** 사용자가 앱이나 AI에 주는 정보
- **Output(결과):** 앱이나 AI가 사용자에게 보여 주는 정보

예: 과목과 시험일을 입력하면(Input), 오늘의 학습 계획이 나온다(Output).

### 사실 확인과 출처

생성형 AI는 그럴듯하지만 틀린 내용을 만들 수 있다. 이를 특별한 용어로 외우기보다 아래 행동을 기억한다.

> 중요한 정보는 원래 자료·공식 기관·날짜를 다시 확인한다.

특히 건강, 법, 진학, 돈, 최신 정보처럼 중요한 내용은 AI 답 하나만으로 결정하지 않는다.

### 개인정보와 비밀 정보

AI 창과 공개 코드에는 아래 정보를 넣지 않는다.

- 내 연락처, 정확한 주소, 비밀번호
- 친구의 개인정보와 사진
- API 키, 계정 토큰, 로그인 정보
- 공개하면 곤란한 학교 문서나 대화 내용

## 프로젝트에서 쓰는 개념 연결

| 개념 | 학생용 설명 | 프로젝트에서 만나는 곳 |
| --- | --- | --- |
| 웹앱 | 브라우저에서 쓰는 프로그램 | 모든 Level의 결과 화면 |
| 챗봇 | 질문에 답하는 AI | 자료 기반 질문 도우미 |
| Workflow | 정해진 순서로 여러 일을 처리하는 흐름 | 입력 → 검사 → 정리 → 출력 |
| Agent | 목표를 보고 필요한 일을 판단하는 AI | Level 2 이후의 문제 해결 도구 |
| MVP | 핵심 기능만 먼저 만드는 첫 제품 | 만들기 → 사용 → 수정 |
| PWA | 웹으로 만들고 앱처럼 사용하는 방식 | Level 1 설치형 생활 앱 |
| API | 다른 서비스의 데이터나 기능을 정해진 방법으로 가져오는 연결 | Level 3 부산 공공데이터 실습 |

`API`는 이번 1차시에 연결의 뜻만 이해하면 됩니다. 실제 키·요청·보안은 Level 3에서 다룹니다.

## 사례 분류 활동 카드

| 사례 | 생각할 질문 | 분류 |
| --- | --- | --- |
| 급식 잔반량을 입력하면 합계와 그래프를 보여 준다. | AI가 있는가? | 일반 웹앱 |
| “우유팩은 어디에 버려?”에 AI가 답한다. | AI가 답을 만드는가? | AI 웹앱 |

| 시험일·현재 실력을 보고 부족 과목과 시간 배분을 판단한다. | 목표와 상황을 보고 판단하는가? | AI Agent |
| 행사 준비 상태를 확인하고 부족한 일을 찾아 계획을 다시 고친다. | 결과를 보고 다음 행동을 바꾸는가? | Agentic AI |

## 안전한 AI 활용 약속

프로젝트를 시작하기 전에 학생과 함께 세 가지 약속을 확인한다.

1. **사실 확인:** 중요한 답은 출처와 날짜를 확인한다.
2. **개인정보 보호:** 나와 다른 사람의 민감한 정보를 AI·공개 코드에 넣지 않는다.
3. **사람의 판단:** AI가 만든 결과를 그대로 제출하거나 실행하지 않고, 내가 읽고 고친다.
