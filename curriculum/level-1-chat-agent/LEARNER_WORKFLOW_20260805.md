# LEVEL 1 학습자 실습 흐름

## 오늘 만드는 것

한 번의 질문에 답하는 프롬프트가 아니라, 자료를 확인하고 여러 단계를 거쳐 결과를 검토하는 `수업 프로젝트 설계 미니 에이전트`를 만든다.

## STEP 0. 기준 예시 체험

두 결과를 비교한다.

- 즉시 생성된 수업안
- 문제 정의, 자료 비교와 테스트를 거친 수업안

기록:

- 더 신뢰할 수 있는 결과:

### 완료 확인

- 문제가 한 번의 수업 또는 한 가지 업무 장면으로 좁혀졌는가?
- 실제 사용자가 결과를 어떻게 사용할지 설명할 수 있는가?
- 성공 여부를 확인할 수 있는가?

### 자료 사용 규칙

- 원문 위치를 확인할 수 없는 요약문은 근거로 쓰지 않는다.
- 자료의 내용과 내가 추론한 내용을 구분한다.
- 학생 이름, 연락처, 성적 등 개인정보는 입력하지 않는다.
- 작성일이 중요한 자료는 최신성을 확인한다.

### Context Packet

```text
[PROJECT]
목적:
사용자:
사용 장면:

[CURRENT STAGE]
현재 단계:

[CONFIRMED]
확정된 결정:

[INPUT]
이번 입력 자료:

[TASK]
이번에 수행할 작업:

[OUTPUT]
출력 형식:

[DO NOT]
금지 사항:

[CHECK]
검증 기준:
```

각 단계가 끝날 때 전체 대화를 다시 보내지 말고 State Snapshot을 저장한다.


| 테스트 | 입력 특징 | 예상 행동 | 실제 행동 | 문제 | 수정 |
